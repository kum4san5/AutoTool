伝説の打鍵感を持つBeam Springキーボードが、Model F Keyboardsから新品として復活。高価なヴィンテージ品に手が届かなかった人にも、現代的なレイアウトとカスタマイズ性で、新しい選択肢が登場したニュースを解説します。

伝説の打鍵感が現代に！何が起きたの？

海外のキーボードメーカー「Model F Keyboards」が、過去にIBMが製造していた「Beam Springキーボード」を新品で再生産し、販売を開始しました。特に注目なのは、最も標準的な「B104」モデルが現代的な104キーレイアウトで提供され、複数のケースカラーやキーキャップの選択肢がある点です。

ヴィンテージのBeam Springキーボードは、状態の良いものだと平気で1000ドル、2000ドルを超えて取引されることも珍しくありませんでした。それが、今回の新品では399ドルからと、かなり手頃な価格帯で手に入れられるようになったのは、キーボード愛好家にとって朗報としか言いようがありませんね。

背景をサクッと整理：Beam Springって何がすごいの？

Beam Springキーボードは、IBMがその後の名機「Model Fキーボード」を世に出す前に、メインフレーム端末向けに製造していたキーボードです。今から約50年前に作られたレジェンドと言ってもいいでしょう。

最大の特徴は、その名の通り「ビーム・スプリング（Beam Spring）」という独特のキースイッチ機構にあります。キーが押されると、細い金属の「ビーム」がたわんで接点に触れる仕組みなんですね。これによって、

  • 深く、はっきりとしたタクタイル（押している感触）フィードバック
  • 心地よいクリック音
  • 耐久性の高さ

といった唯一無二の打鍵感が生まれるんです。例えるなら、タイプライターのメカニカルな感触を、電子機器向けに最適化したようなイメージでしょうか。現代のメカニカルキーボードとは一線を画す、その「打ってる感」が多くの人を魅了し続けているわけです。

ここで知っておきたい用語たち

いくつか専門用語が出てきたので、簡単に補足しておきましょう。

  • Beam Spring（ビーム・スプリング）: 上で説明した、このキーボードの心臓部となるキースイッチの機構です。独自の打鍵感を生み出します。
  • Model Fキーボード: Beam Springキーボードの後継にあたる、IBMの別の名作キーボード。今回のメーカー名にもなっているくらい、こちらも高い人気を誇ります。
  • MXキーキャップ互換: 現代の多くのメカニカルキーボードで採用されている「Cherry MX」という規格のキースイッチに対応したキーキャップが使える、という意味です。つまり、キーキャップを交換して自分好みにカスタマイズしやすいってことですね。
  • ソレノイドドライバー: これはオプションで追加できるパーツです。これを導入すると、キーを打つたびに「カシャン！」という、まるで昔のタイプライターや端末のような特徴的な機械音を鳴らすことができます。ロマンを感じますね！

これって、自分たちにどう関係あるの？

今回の新Beam Springキーボードの登場は、特にキーボードにこだわりたいエンジニアやクリエイターにとって、無視できない選択肢になるはずです。

1. 憧れの打鍵感を「新品」で体験できる

これまでBeam Springの打鍵感は、高価なヴィンテージ品か、マニアックな自作コミュニティでしか味わえないものでした。それが新品で手に入ることで、メンテナンスの心配も少なく、気軽にその魅力を体験できるようになります。毎日コードを書いたり、文章を打ち込んだりする自分たちにとって、入力デバイスの快適さは生産性に直結しますからね。

2. 現代的な使いやすさとの融合

ヴィンテージ品は当時のレイアウトが基本で、現代のPCに繋ぐのも一苦労ということもあります。しかし、今回発表された新製品は、ANSIやISOといった現代の標準的なレイアウトに対応。さらに、MXキーキャップ互換のおかげで、好みのキーキャップに交換して見た目もカスタマイズできるのは大きなメリットです。

3. コストパフォーマンスの向上

前述の通り、オリジナルのBeam Springキーボードはコレクターズアイテム化しており、非常に高価です。今回の新品は$399からという価格設定で、確かに安価ではないですが、その唯一無二の体験と新品である安心感を考えれば、十分検討に値する選択肢になったと言えるでしょう。
